**Footer** — navy site footer: logo, description, link columns, office contact + socials.

```jsx
<Footer />
<Footer phone="(215) 352-5111" email="hello@tcsgroup.com" />
```

Social icons use Lucide (load the CDN `lucide` script and call `lucide.createIcons()`). Override `columns`, `address`, `phone`, `email` as needed.
